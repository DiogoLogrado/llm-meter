A small status bar meter for Ollama Cloud usage limits:

```
🤖 43% 2h · 88% 3d
```

One status bar item showing session and weekly usage, tinted by a colour ramp driven by the
higher of the two, with the time until each window resets. You can hover for the details and the tooltip also has Refresh button, and a "Gear" button to set the thresholds. Local install only: no marketplace, no telemetry, no auto-update, no dependencies for now.

## Files

Three main files:

- [src/request.js](src/request.js): the network request, and nothing else.
- [src/ui.js](src/ui.js): the status bar text, colours, tooltip and refresh behaviour.
- [src/config.js](src/config.js): the numbers and switches you might change.

The request:

```
GET https://ollama.com/api/balance
Authorization: Bearer <your Ollama API key>
```

- Redirects are refused, so the key cannot be forwarded to another host.
- Nothing is logged.
- The key is stored in VS Code Secret Storage (OS keychain), or read from the `OLLAMA_API_KEY` environment variable.

The balance endpoint is undocumented, so it may change or behave differently from what is assumed here. If it stops working, please open an issue.

## Build and install

You need [Node.js](https://nodejs.org) 18 or newer. If the version is too old the
build stops with a clear message instead of a stack trace. With
[nvm](https://github.com/nvm-sh/nvm) (or nvm-windows) run `nvm install` first to
pick up the version in `.nvmrc`.

```powershell
git clone <this repo>
cd llm-meter
npm run package            # checks Node, then creates dist/llm-meter-ollama.vsix
npm run package:ollama     # the same, spelled out per provider
```

Providers are plain npm scripts in `package.json`; Ollama is the only one today.
Adding one in the future (Claude) is a new `package:<provider>` line.

Then in VS Code:

1. Press `Ctrl+Shift+P` (`Cmd+Shift+P` on macOS) to open the Command Palette.
2. Run **Extensions: Install from VSIX...**
3. Pick `dist/llm-meter-ollama.vsix`.
4. Reload the window if asked.

Command line alternative: `code --install-extension dist/llm-meter-ollama.vsix`.

To update, rebuild the `.vsix` and install it again.
To remove it, uninstall "LLM Meter" from the Extensions view.

A `.vsix` is just a zip file, so you can rename a copy to `.zip` and look inside: the source ships readable and unminified, next to `package.json`, the LICENSE, the README and the icon. No bundled dependencies, nothing obfuscated.

## Use

1. Run **LLM Meter: Set API Key** from the Command Palette.
2. The meter appears in the status bar.

**LLM Meter: Set Refresh Interval** changes how often usage is checked (0 turns the timer off).
**LLM Meter: Set Threshold Percentages** changes the two thresholds.
Everything else lives in [src/config.js](src/config.js).

## Change how it looks

Edit `src/config.js` for the gradient colours and the focus refresh, or `src/ui.js` for the status bar text and tooltip. Rebuild and reinstall afterwards.
